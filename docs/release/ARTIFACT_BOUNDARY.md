# Generated Artifact Boundary

This repository keeps generated evidence only when it has an explicit role.
Runtime output roots are ignored by default; promoted files must move into a
source-controlled fixture, archive, or release-artifact location.

## Directory Policy

| Path | Tracked contents | Classification | Notes |
| --- | --- | --- | --- |
| `artifacts/paper/` | Yes, allowlisted files in `manifest.json` | Source-controlled release artifacts | Deterministic Paper Core artifacts generated by `scripts/reproduce_paper.py` and verified by `scripts/verify_paper_artifacts.py`. |
| `paper/figures/` | Yes, allowlisted manuscript figures | Paper source artifacts | Figures used by the manuscript/source docs. Do not use this path for scratch experiment plots. |
| `tests/fixtures/` | Yes | Test fixtures | Small, stable inputs needed by tests. The Week 5 golden scan lives in `tests/fixtures/week5_scan/scan.csv`. |
| `examples/` | Yes | Example source and labeled example inputs | Examples should be runnable source or clearly labeled static inputs, not fresh runtime output. |
| `docs/archive/` | Yes | Historical archived examples | Preserved evidence that is not a live release artifact or fixture. Historical checkpoints and generated results live here. |
| `results/` | README marker only | Runtime-only | Local generated result payloads are ignored. Promote reviewed outputs before tracking them. |
| `checkpoints/` | README marker only | Runtime-only | Local checkpoint payloads are ignored. Historical examples are archived under `docs/archive/generated-checkpoints/`. |
| `runs/` | README marker only | Runtime-only | Local audit logs, manifests, and run ledgers are ignored. |
| `figs/` | README marker only | Runtime-only | Local diagnostic figures are ignored. |
| `figures/` | README marker only | Runtime-only | Local experiment figures are ignored. Paper figures belong in `paper/figures/`. |

The tracked `theory/icse/lesson1/runs/q1/` files are a historical theory
archive, not root runtime output. New root-level `runs/` payloads remain ignored.

## Promotion Workflow

Generated output graduates into source control only after review:

1. Regenerate into the normal runtime location, such as `results/`,
   `checkpoints/`, `runs/`, `figs/`, or `figures/`.
2. Decide its role:
   - test input: move it under `tests/fixtures/`;
   - historical evidence: move it under `docs/archive/` with a README note;
   - Paper Core release evidence: regenerate into `artifacts/paper/` and update
     the paper artifact manifest;
   - manuscript source figure: move it under `paper/figures/` and update the
     allowlist in `scripts/check_artifact_boundary.py` if it is intentionally
     tracked.
3. Update all tests, docs, scripts, and Makefile targets that referenced the old
   runtime path.
4. Run the boundary check:

```bash
make check-artifact-boundary
```

For a short reproducibility diff firewall, run:

```bash
make check-repro-clean
```

`make check-repro-clean` captures the existing git status, runs a small
deterministic reproduction sequence into a temporary directory, and fails if the
sequence creates new tracked diffs or untracked files outside allowed generated
locations.
