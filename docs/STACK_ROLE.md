# Stack Role: cc-framework

cc-framework is a research kernel for dependence-aware guardrail composition.

Its responsibility is not product UI, branding, dashboards, or enterprise
workflow. Its responsibility is the measurable core:

- dependence-aware guardrail composition
- Fréchet-Hoeffding bounds
- composition coefficient computation
- regime classification
- deterministic evidence bundles
- manifests, hashes, ledgers, and attestations
- reproducible experimental outputs

This repository should remain the place where bounded claims become explicit
mathematical assumptions, deterministic computations, and auditable local
evidence. It is not an enterprise product, a dashboard release, or a deployment
safety certification.
